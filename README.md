# Lunch Decision App

This project helps teams decide on lunch by voting on different menus.

## Project Structure

```
lunch-decision/
├── backend/            # Express.js Server
│   ├── src/            # Source files
│   └── package.json    # Backend dependencies
├── frontend/           # React Application
│   ├── src/            # React components and pages
│   └── package.json    # Frontend dependencies
└── README.md           # This file
```

## Getting Started

### Backend Setup
1. `cd backend`
2. `npm install`
3. `npm run dev`

### Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm start`
